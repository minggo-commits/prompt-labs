# Welcome to The Hub

PromptLabs is a definitive open-source guide for mastering **Prompt Engineering Techniques**. 

Rather than relying on brittle, copy-paste templates, this guide teaches you the fundamental principles and methodologies that allow you to control Large Language Models (LLMs) effectively, no matter the specific use case.

## What You Will Learn
* **Conditioning Data**: How to use Zero-Shot and Few-Shot prompting to guide model outputs.
* **Reasoning Flow**: Eliciting deep logic via Chain-of-Thought and Step-Back Reasoning.
* **External Knowledge**: Grounding models with Retrieval-Augmented Generation (RAG).
* **Tool Orchestration**: Getting models to reliably synthesize logic with external tools (ReAct).

Choose a technique from the sidebar to start mastering AI.
